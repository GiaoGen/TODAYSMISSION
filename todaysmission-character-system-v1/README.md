# TODAYSMISSION Character System v1

This package is the approved character production baseline for TODAYSMISSION.

It contains seven locked production characters:

1. Dinosaur
2. Sheep
3. Owl
4. Red Panda
5. Otter
6. Rabbit
7. Penguin

Each character folder contains exactly four core assets:

- `canonical-model.png` — visual identity reference
- `acting-stress-test.png` — validated acting elasticity reference
- `character-lock.md` — full authoritative identity specification
- `prompt-fragment.md` — compact production prompt module

## Start Here

1. Read `asset-manifest.md`.
2. Read `canonical-model-style-lock.md`.
3. For artwork generation, provide the relevant `canonical-model.png` plus the character's `prompt-fragment.md`.
4. For QA or drift disputes, consult `character-lock.md`.
5. Use `acting-stress-test.png` only to understand allowed deformation / acting range.

## Important

Characters are already designed.

Downstream generation should not ask an image model to "design a cute dinosaur / sheep / owl / ...".

Instead, treat the character identity as locked and spend creative freedom on acting, scene, composition, props, clothing, accessories, camera and storytelling.
